# CSS Quality
1. Define cascade strategy.
2. Control specificity.
3. Use tokens for repeatable decisions.
4. Use logical properties where sensible.
5. Use fluid sizing.
6. Ensure focus styles are visible.
7. Respect reduced motion.
8. Prevent overflow.
9. Respect intrinsic sizing.
10. Avoid arbitrary z-index escalation.
11. Avoid excessive !important.
12. Avoid fixed heights around dynamic content.
13. Avoid magic numbers without rationale.
14. Avoid copied utilities without understanding.
15. Avoid invisible focus indicators.
