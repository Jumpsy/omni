# Typography Systems
1. Choose fonts by reading need and personality.
2. Limit weights.
3. Set roles: display, heading, body, label, data, code.
4. Keep body measure readable.
5. Prevent awkward heading wraps.
6. Use tracking intentionally.
7. Use line height to support density.
8. Do not use bold for every label.
9. Validate fallback fonts.
10. Check loading states in screenshots.
11. Match type scale to screen density.
12. Prefer clarity over novelty.
13. Avoid default system fonts unless they fit the product.
14. Keep code and tabular data legible.
15. Use typography to define hierarchy before color does.
