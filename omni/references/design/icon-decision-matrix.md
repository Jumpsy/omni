# Icon Decision Matrix
1. Reuse existing icon set first.
2. Use one family only.
3. Match stroke weight to density.
4. Decide filled vs outline consistently.
5. Give unfamiliar icons labels.
6. Use icons for concepts, not decoration.
7. Do not add icons to every heading.
8. Use accessible names for interactive icons.
9. Verify optical alignment.
10. Avoid emoji.
11. Avoid text glyph substitutes.
12. Prefer text when text is clearer.
13. Reserve custom icons for brand concepts.
14. Explain why each icon is recognizable.
15. Explain where each icon appears.
