# Information Architecture
1. Map entities.
2. Map tasks.
3. Map states.
4. Map navigation.
5. Identify primary and secondary actions.
6. Order content by user priority.
7. Keep labels short and specific.
8. Make empty states useful.
9. Make errors recoverable.
10. Preserve hierarchy on mobile.
11. Surface critical state changes.
12. Avoid hidden actions for core tasks.
13. Prefer fewer levels when depth is unnecessary.
14. When content is dense, group by intent.
15. Validate IA against real use cases.
