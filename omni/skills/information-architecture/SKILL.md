# Information Architecture
Purpose: define hierarchy, grouping, labels, and screen map.
Workflow: map entities, tasks, states, primary and secondary paths, then validate against mobile and error cases.
Outputs: sitemap, hierarchy, state list.
Failure: when content order is driven by decoration rather than task priority.
See [IA reference](../../references/design/information-architecture.md).
