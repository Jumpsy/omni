# Art Direction
Purpose: pick one coherent visual direction and document the reasons.
Workflow: create 3 directions, compare them, choose one, define tokens, anti-slop rules, and image logic.
Outputs: visual-direction note, token seeds, asset requirements.
Failure: more than one direction is blended.
See [art direction reference](../../references/design/art-direction.md) and [imagery](../../references/design/imagery-art-direction.md).
