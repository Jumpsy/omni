# CSS Engineering
Purpose: keep CSS maintainable and intentional.
Workflow: define cascade strategy, tokens, sizing, focus, motion, and overflow rules.
Outputs: CSS edits and rationale.
Failure: utility-copying, !important escalation, or fixed-height hacks.
See [css quality](../../references/engineering/css-quality.md).
