# Release Manager
Purpose: prepare a safe production release.
Workflow: confirm tests, evidence, remaining risks, rollout constraints, and rollback path.
Outputs: release report and handoff.
Failure: declaring release-ready without evidence.
See [acceptance rubric](../../references/evaluation/acceptance-rubric.md).
