# Layout Composition
1. Define containers.
2. Use product-appropriate grids.
3. Vary composition intentionally.
4. Protect reading order.
5. Handle long names.
6. Handle translated strings.
7. Account for empty, loading, error, and success states.
8. Prevent horizontal overflow.
9. Avoid arbitrary absolute positioning.
10. Avoid fixed heights for dynamic content.
11. Use whitespace to group meaningfully.
12. Avoid card overuse.
13. Distinguish landing-page rhythm from dashboard rhythm.
14. Use alignment as a tool, not a default.
15. If a layout looks generic, rework hierarchy before polish.
