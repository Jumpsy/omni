# Art Direction
1. Create three directions.
2. Select one.
3. Explain why it fits the product.
4. Do not blend directions into mush.
5. Define type, spacing, color, and surface logic.
6. Define image treatment.
7. Define icon treatment.
8. Define interaction tone.
9. Define mobile adaptation.
10. Define exception cases.
11. Use restraint on decoration.
12. Use negative space intentionally.
13. Make product value visible.
14. Design for evidence, not vibes.
15. Write the anti-reference clearly.
