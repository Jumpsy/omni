# Testing Strategy
1. Test meaningful behavior.
2. Include integration tests when backend work exists.
3. Include browser verification for visual work.
4. Include responsive checks.
5. Include keyboard checks.
6. Include console checks.
7. Include network checks.
8. Include loading/error/empty states.
9. Compare before/after for redesigns.
10. Do not rely on screenshots alone.
11. Do not rely on unit tests alone.
12. Record exact failing cases.
13. Re-run after fixes.
14. Keep tests targeted.
15. Report gaps honestly.
