# Browser Verification
1. Start the app.
2. Navigate all relevant routes.
3. Capture desktop and mobile screenshots.
4. Inspect console errors.
5. Inspect failed requests.
6. Check overflow.
7. Test keyboard navigation.
8. Test loading and error states.
9. Exercise primary interactions.
10. Record performance when relevant.
11. Save evidence in evals or artifacts.
12. Verify responsive breakpoints.
13. Use rendered proof for visual changes.
14. Do not claim a fix without a new screenshot.
15. Compare before and after when redesigning.
