# Acceptance Rubric
1. Score at least 88 overall.
2. No category below 7 after normalization.
3. No critical accessibility failures.
4. No broken layouts.
5. No placeholder content as final.
6. No unresolved high-severity anti-slop issues.
7. Evidence must be screenshot-backed when visual.
8. Tests must be run for functional work.
9. Limitations must be documented.
10. Evidence locations must be listed.
11. Release readiness needs rollback awareness.
12. Source code alone is not proof.
13. Multiple critique cycles are expected for major UI.
14. Lower scores must trigger revision.
15. Inflate scores only if the evidence justifies it.
