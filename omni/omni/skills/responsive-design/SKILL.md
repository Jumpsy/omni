# Responsive Design
Purpose: ensure 390, 768, 1024, 1440, and 1920 layouts all remain usable.
Workflow: test each breakpoint, adapt navigation, density, tables, forms, modals, and focus order.
Outputs: breakpoint notes and fixes.
Failure: desktop layout shrunk to mobile.
See [mobile adaptation](../../references/design/mobile-adaptation.md).
