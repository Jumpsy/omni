# UX Flows
Purpose: define user journeys and state transitions.
Workflow: map entry, action, success, error, recovery, and exit for each flow.
Outputs: flow diagram in text, state matrix, open questions.
Failure: missing error, loading, or empty states.
See [ux flows](../../references/design/ux-flows.md).
