# Iconography
Purpose: choose one icon family and justify each icon.
Workflow: reuse existing icons first, match stroke and density, label uncertain icons.
Outputs: icon decision matrix.
Failure: mixed icon families or emoji as production icons.
See [icon matrix](../../references/design/icon-decision-matrix.md).
