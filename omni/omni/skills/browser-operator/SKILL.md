# Browser Operator
Purpose: verify the actual rendered product.
Workflow: start app, navigate, capture desktop/mobile screenshots, inspect console/network, test keyboard and overflow.
Outputs: screenshot evidence and interaction notes.
Failure: relying on source code without rendered proof.
See [browser verification](../../references/engineering/browser-verification.md).
