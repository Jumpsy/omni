# Frontend Implementation
Purpose: build the actual interface, not just mock it.
Workflow: implement smallest viable pieces, keep semantic HTML, handle states, test, and inspect rendered results.
Outputs: production code, tests, and screenshots.
Failure: giant monolithic components or hardcoded final mocks.
