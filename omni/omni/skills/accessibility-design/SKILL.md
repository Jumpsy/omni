# Accessibility Design
Purpose: build accessibility into the interface and verify it visually.
Workflow: check semantics, focus, labels, motion, touch targets, zoom, and screen reader naming.
Outputs: accessibility notes and fixes.
Failure: automated checks pass while keyboard or visual inspection fails.
See [accessibility](../../references/design/accessibility-checklist.md).
