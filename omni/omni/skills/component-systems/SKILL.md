# Component Systems
Purpose: derive components from product needs, not the other way around.
Workflow: define purpose, variants, states, keyboard behavior, responsive behavior, and limits.
Outputs: component matrix and state list.
Failure: generic library before product understanding.
See [component states](../../references/design/component-state-matrix.md).
