# Testing Quality
Purpose: require tests and evidence for meaningful changes.
Workflow: run relevant lint, type, unit, integration, and browser checks; record failures and fixes.
Outputs: test report and evidence links.
Failure: claiming completion without execution.
See [testing strategy](../../references/engineering/testing-strategy.md) and [browser verification](../../references/engineering/browser-verification.md).
