# Imagery Direction
Purpose: decide when to use screenshots, photos, illustrations, diagrams, data, or generated imagery.
Workflow: create asset manifest, define crop and alt text, inspect every image, reject mismatches.
Outputs: manifest, prompts, and asset notes.
Failure: decorative images used to hide missing product understanding.
See [imagery reference](../../references/design/imagery-art-direction.md).
