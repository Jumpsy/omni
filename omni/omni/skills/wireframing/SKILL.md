# Wireframing
Purpose: sketch structure before visual styling.
Workflow: block layout, review hierarchy, test content density, then freeze structure.
Outputs: low-fi screen map and element order.
Failure: jumping straight to implementation before hierarchy is validated.
See [layout](../../references/design/layout-composition.md).
