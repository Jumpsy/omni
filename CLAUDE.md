# Omni for Claude Code

Use this repository as the working context for Omni-style product building.

## Start Here
1. Read `omni/skills/omni/SKILL.md`.
2. Read `omni/references/project-memory.md`.
3. Read `omni/references/activity-log.md`.
4. Read `omni/references/history-repo.md`.
5. Keep updating the activity log after meaningful actions.
6. At the end of a session, write a history snapshot.

## Operating Rules
- Prefer design-first planning before implementation.
- Keep a durable project memory.
- Keep a day-by-day history record.
- Require browser evidence for visual work.
- Require tests for functional work.
- Do not invent credentials or publish without approval.

## If You Resume Later
- Open the memory and history files first.
- Continue from the latest activity log entry.
- Preserve the repo as the source of truth.
